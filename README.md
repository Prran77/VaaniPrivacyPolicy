# Vaani Privacy Policy

A professional, dark-themed privacy policy website for the **Vaani** mobile application - a voice-to-text conversion app for Android.

## 📱 About Vaani

Vaani is a lightweight voice-to-text application that processes audio locally on your device with no data collection or transmission to external servers. It respects user privacy by keeping all processing on-device.

## 📄 What's in This Repo

This repository hosts the privacy policy for Vaani, published as a static GitHub Pages website with the following features:

### Features
- ✨ **Dark Theme** - Professional GitHub-inspired dark mode with blue accent colors
- 📑 **Table of Contents** - Quick navigation links to all policy sections
- ⬆️ **Back to Top Button** - Smooth scroll navigation on longer pages
- 🔍 **SEO Optimized** - JSON-LD schema and meta tags for better discoverability
- 🖨️ **Print Friendly** - Optimized styling for saving/printing as PDF
- 📱 **Fully Responsive** - Works perfectly on mobile, tablet, and desktop
- ⚡ **Fast & Lightweight** - Pure HTML/CSS with minimal JavaScript
- 🎯 **Accessibility Ready** - Semantic HTML and ARIA labels

## 🚀 Quick Start

### View Locally
Simply open `index.html` in your web browser to preview the privacy policy.

### Deploy to GitHub Pages
1. Push this repository to GitHub
2. Go to repository **Settings → Pages**
3. Set source to **main branch**
4. Your privacy policy will be live at: `https://yourusername.github.io/VaaniPrivacy/`

## 📋 Privacy Policy Sections

The policy covers:
1. **Information Collection & Use** - Details on data handling practices
2. **Device Permissions** - Microphone access and local processing
3. **Third-Party Services** - Google Play Services and AdMob integration
4. **Data Retention** - User data control and deletion
5. **Children's Privacy** - COPPA compliance (13+ requirement)
6. **Policy Changes** - How updates are communicated
7. **Contact Information** - Email support for privacy inquiries

## 🔧 Customization

### Update Contact Email
Edit the email in the "Contact Us" section:
```html
<a href="mailto:your-email@example.com">your-email@example.com</a>
```

### Update Last Modified Date
Change the timestamp:
```html
<p class="timestamp"><strong>Last Updated:</strong> Your Date Here</p>
```

### Customize Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --accent-primary: #58a6ff;      /* Main blue accent */
    --accent-secondary: #79c0ff;    /* Light blue accent */
    --text-primary: #e6edf3;        /* Main text color */
    /* ... more colors */
}
```
